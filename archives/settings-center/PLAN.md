# Arch Linux 集中設定中心

> **已封存：不使用，僅保存。** 以下為原計畫，非目前執行中的工作或部署規格。實作完成程度請參閱 [README.md](README.md)。

## 目標與介面

以現有 Quickshell 元件建立獨立設定應用，使用自己的程序及一般 Wayland 視窗；桌面 Quickshell 未啟動或重載時仍可使用。

- 提供 `.desktop` 入口，可在 Launcher 搜尋「設定」、「Settings」開啟；重複啟動會聚焦既有視窗。
- 採繁體中文、現有灰黑玻璃風格，左側分類、右側設定，支援搜尋設定項目。
- 視窗可移動、縮放；桌面面板增加設定入口。
- 每頁提供「套用／還原修改」，離開未保存頁面時提示處理。音量、靜音、連線等操作即時生效。

## 實作與設定保存

- 新增獨立 Quickshell 入口，重用共用樣式、控制元件與服務程式碼。獨立程序不建立第二個通知伺服器；通知設定經本機設定檔同步給桌面。
- 使用明確的應用識別與指定設定路徑的 IPC，提供 `settings show`、`settings openPage(pageId)`，避免呼叫到桌面程序。
- 本機偏好統一保存在 `$XDG_CONFIG_HOME/settings-center/settings.json`；預設位置為 `~/.config/settings-center/settings.json`。視窗位置等狀態放在 XDG state 目錄。
- 設定後端採 Python，透過現有 JSON process 模式與 QML 溝通，提供讀取、能力查詢、驗證、套用和還原；系統服務使用既有 Quickshell API、Gio D-Bus 或指定參數的工具命令。
- Hyprland、Kitty 加入本機覆寫檔載入點；Quickshell 樣式讀取本機偏好；桌布與登入啟動使用本機產生的設定。儲存庫保留程式碼、預設值與載入橋接，日常調整不修改 Git 追蹤檔，也不破壞 Stow 連結。
- 初次開啟只讀取現況，不自動套用預設值。只保存使用者修改的項目；移除覆寫後回到原有設定。
- 網路、音訊、VPN、帳號與日期時間由原系統服務保存；密碼、私鑰不寫入共用偏好檔或日誌。
- Hyprland 同時處理即時套用與登入後持久化，因為單次 runtime 修改會在重載後失效。[Hyprland 官方說明](https://wiki.hypr.land/configuring/core/config-options/)

## 套用與失敗處理

- 保存前檢查格式、範圍及後端能力；原子寫入並保留上一份有效設定。失敗時顯示原因，避免把未成功的操作標為已套用。
- 螢幕變更先暫時套用，15 秒內確認才保存；逾時、取消或視窗退出後，由獨立還原程序恢復上一份配置。
- 系統授權使用現有 Polkit；取消授權時保留原值。設定應用本身以一般使用者執行。
- 缺少套件、服務或裝置時，保留分類並說明不可用原因，不自動安裝。外部修改與尚未保存的編輯衝突時，提示重新載入。
- Kitty 等無法可靠即時套用的項目，明確標示於新視窗或下次登入生效。

- 驗證 Launcher 搜尋、獨立啟動、重複啟動聚焦、視窗縮放，以及桌面程序停止時的使用。

- 驗證螢幕確認、逾時與程序退出還原；以模擬後端測試斷線、密碼錯誤、取消授權和裝置移除。
- 實機確認音訊、網路、桌面設定同步、重啟後保存及時區顯示；執行相關既有 Quickshell 回歸檢查。
- 預設延續目前外觀及操作值；系統時鐘顯示先保留現有 UTC，讓使用者自行切換。
- 原計畫確認設定檔與套件清單時，即時桌面及系統匯流排查詢受沙箱限制，實作驗收時須補查實際能力。
